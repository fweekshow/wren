# Wren iOS — UI kit
Four 390×844 screens side by side, live-linked: Send flashes Someone; picking a person updates Amount and Sent; keypad, presets, stock pills and pay choice all work; Continue → Sent; Home → Home.
Pick someone without Wren (Priya, Leo…) to see "They'll get a text."
Files: `data.js` (stocks, holdings, people), `HomeScreen.jsx`, `SomeoneScreen.jsx`, `AmountScreen.jsx`, `SentScreen.jsx`, `index.html`. All primitives come from the bundle (`window.WrenDesignSystem_f754eb`).

The mascot is temporarily removed from these screens until final pose art arrives.
